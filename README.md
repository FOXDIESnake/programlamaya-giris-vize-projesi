Proje hakkında

Bu proje, Türk masallarını tek bir web sayfasında toplamak için hazırlandı. Sayfada masalları okuyabilir, arama kutusunu kullanarak başlık veya metin içinde kelime arayabilirsiniz.

Sayfada bulunan masallar
- Keloğlan ve Dev
- Zümrüdü Anka
- Şahmeran
- Kırk Haramiler
- Nardaniye
- Limon Kız
- Keloğlan ve Padişahın Kızı
- Kıymetli Tuz


Projede HTML ile sayfanın yapısı, CSS ile tasarımı, JavaScript ile de arama özelliği oluşturulmuştur. CSS ve JavaScript kodları ayrı dosyalarda tutulmaktadır.
Dosyalar
- index.html: Sayfanın ve masal içeriklerinin bulunduğu dosya.
- style.css: Renkleri, yazı tiplerini ve sayfanın görünümünü düzenler.
- script.js: Arama özelliğini çalıştırır.
- README.md: Proje hakkında bilgi verir.

Nasıl kullanılır?
1. Proje dosyalarını aynı klasöre çıkar.
2. index.html dosyasını bir web tarayıcısında aç.
3. Masalları okumak için sayfayı kullanabilir, arama kutusuna bir kelime yazarak masalları filtreleyebilirsin.
